Decoupling style
per resolution.

StyleGAN feeds the same latent code to every resolution layer — causing blobbing artifacts on abstract art. We propose four mapping-network variants that give each scale its own style vector, cutting Wasserstein loss by ~25% with under half the parameters.

By Ho Ko · Meng Yuan — ECE, University of Waterloo

Four variants
One style vector per resolution layer.
VARIANT 1

Direct injection

Nine parallel heads, each emitting a separate wᵢ. Full independence; highest parameter count.

VARIANT 2

Shared-then-branched

A shared 4-layer trunk feeds four branches — balancing parameter sharing with resolution independence.

VARIANT 3

Residual mapping

wᵢ = w_base + Δwᵢ — fine per-layer adjustment without discarding the globally disentangled base.

VARIANT 4

Compressed

FC(128)×6 + 9 lightweight heads. The bottleneck regularizes — learning a compact, disentangled style instead of memorizing texture.
